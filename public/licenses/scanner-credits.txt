Badge greeting scanner

Inspiration and thanks:
Rob Bos / Xebia, badge-scanner
https://github.com/xebia/badge-scanner
No source code was copied or adapted from badge-scanner. The repository did not
declare a license when this independently implemented integration was added.

Printed badge text is recognized locally by Tesseract.js. The English model is
bundled from @tesseract.js-data/eng and is processed on-device. The npm package
declares MIT; its upstream tessdata repository identifies the model files as
Apache-2.0. Both notices are included.
https://github.com/naptha/tessdata
Full licenses are included in tesseract-js-APACHE-2.0.txt,
tesseract-core-APACHE-2.0.txt, and tesseract-data-MIT.txt.
